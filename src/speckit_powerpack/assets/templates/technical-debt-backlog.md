# Technical Debt Backlog

> Managed with the SpecKit PowerPack technical-debt lifecycle. Project policy may extend this format, but stable IDs, provenance and resolution evidence must be preserved.

## Conventions

- Status: `OPEN`, `IN_PROGRESS`, `RESOLVED`.
- Readiness: `READY`, `BLOCKED`, `NEEDS_REFINEMENT`, `RESOLVED`.
- Default priorities: `P1`, `P2`, `P3`. P0/BLOCKER work belongs to the delivery flow that discovered it and must not be created here.
- IDs are stable and never reused or renumbered.
- Historical text/provenance is append-preserving across lifecycle changes.
